# 🌿 متجر الأعشاب

تطبيق PWA لإدارة منتجات ومبيعات محل أعشاب وتوابل.

## المميزات
- 📦 إدارة المنتجات (بباركود / بدون / بالوزن)
- 📷 مسح Barcode و QR Code بالكاميرا
- 🛒 نقطة بيع سريعة (POS)
- ✨ توليد وصف المنتجات تلقائياً عبر Grok API
- 📊 إحصائيات يومية وشهرية
- 💾 نسخ احتياطي / استيراد JSON
- 📱 يعمل كتطبيق هاتف (PWA)

## التشغيل

```bash
npm install
npm run dev
```

## النشر على GitHub Pages

```bash
npm run build
```

ثم ارفع مجلد `dist` على GitHub Pages.

## الإعدادات
أدخل مفتاح Grok API من صفحة الإعدادات داخل التطبيق.
المفتاح يُحفظ محلياً ولا يُرفع لأي سيرفر.
